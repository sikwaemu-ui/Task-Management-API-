## Short description

**TaskFlow — Task Management REST API**  
Built a TypeScript and Express REST API for personal and collaborative task management, with JWT authentication, PostgreSQL persistence through Prisma, role-based team permissions, API validation, production hardening, and interactive OpenAPI documentation.

## CV bullets

- Developed a REST API with TypeScript, Express 5, Prisma 7, and PostgreSQL for accounts, personal tasks, teams, memberships, and collaborative task workflows.
- Implemented JWT authentication, bcrypt password hashing, Zod validation, structured errors, and role-aware access control for team and task operations.
- Added task search/filter/sort and pagination, Helmet, configurable CORS, request logging, rate limiting, environment validation, and graceful shutdown.
- Built a GitHub Actions CI workflow using Node.js 22 and PostgreSQL 16 to validate/generate Prisma, apply migrations to a temporary database, run automated tests, and build the application.
- Deployed the API to Render with Neon PostgreSQL, using environment-based database credentials, versioned Prisma migrations, and an HTTP health endpoint. The current service URL and health were not independently verifiable during this documentation update.
